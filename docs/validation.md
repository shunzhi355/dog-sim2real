## 板端环境变更

安装 `python3-venv`、`python3-pip` 等所需包；APT 为依赖匹配将 Python 3.10.12 的 Ubuntu 包修订升级至 `1~22.04.18`。项目依赖装入自己的 `.venv`，主要包版本保存在 `deploy/constraints-orangepi-py310.txt`。

更新软件索引时发现原系统 Docker 阿里源缺少公钥，保留原配置，没有关闭签名校验或替换源。Ubuntu 官方发行包镜像索引更新后，Python 依赖安装成功。这个 Docker 源问题不影响当前框架，但以后维护 APT 时需单独处理。

上述初始部署验证时未修改 boot 配置、未重启、未打开物理舵机串口或 I2C、未发送 LOAD/MOVE、未安装启动 systemd 服务、未启动开机运动。后续 UART 启用与回读测试见下方更新记录，不能将初始部署状态当作当前状态。

ONNX Runtime 在 ARM 环境启动时输出 GPU 设备节点探测警告；实际 Session 明确使用 `CPUExecutionProvider`，推理及测试通过。该提示不表示本工程需要 GPU/CUDA。
